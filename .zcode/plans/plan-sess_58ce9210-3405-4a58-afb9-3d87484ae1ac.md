# HiKey M1 脚手架实施计划

## 目标（PRD §11 M1）
项目初始化、依赖、electron-vite/builder 配置、空白窗口跑通。本里程碑不写任何业务逻辑（crypto/storage/healthCheck/scheduler/importer/backup/ipc/providers 全部留到 M2–M6）。

## 关键决策（已与你确认）
- **不另写文档**：现有 3 份版本化文档（PRD/技术栈/数据库设计）是单一事实来源，M1 计划为其执行合成；代码 + commit 即记录，避免重复与过时。
- **目录骨架**：只建入口 + 配置文件。业务文件按技术栈 §7 留到各自里程碑，不建空占位。
- **shadcn 基础设施**：M1 手动搭好 `components.json` + `src/lib/utils.ts` 的 `cn()` + Tailwind 的 shadcn 主题 CSS 变量（不跑 shadcn CLI、不联网）。实际组件（Dialog/Table/Switch 等）M6 用 `npx shadcn add` 按需引入。
- **依赖粒度**：M1 只装"空白窗口 + shadcn 基建"所需依赖。lowdb 推迟到 M2、dotenv 推迟到 M4、全部 `@radix-ui/react-*` 推迟到 M6（技术栈 §3 标注 Radix"按需安装"）。

## 结构对齐说明
技术栈 §7 的结构与 electron-vite 默认模板不同：主进程/preload 放在 `electron/`（而非 `src/main`），渲染进程放在 `src/`。本计划以技术栈 §7 为准，通过在 `electron.vite.config.ts` 自定义 entry 路径与 renderer root 对齐。

## 文件清单（共约 20 个，全部为入口/配置）

### 根配置
1. **`package.json`** - `name: hikey`、`productName: HiKey`（决定 `app.getPath('userData')` = `%APPDATA%/HiKey`，与数据库设计一致）、`version: 0.1.0`、`main: out/main/index.js`。scripts：`dev`=`electron-vite dev`、`build`=`electron-vite build`、`preview`=`electron-vite preview`、`package`=`electron-vite build && electron-builder`、`typecheck:node`/`typecheck:web`/`typecheck`。
2. **`electron.vite.config.ts`** - 三目标配置：main entry=`electron/main/index.ts`、preload entry=`electron/preload/index.ts`、renderer root=`src`、input=`src/index.html`；renderer 加 `@vitejs/plugin-react` 与 `@`->`src` 路径别名；main/preload 用 `externalizeDepsPlugin()`。
3. **`electron-builder.yml`** - `appId: com.hikey.app`、`productName: HiKey`、win target=`nsis`（非 one-click、可改安装目录）、`directories.buildResources: resources`。图标 M6 再加（M1 不阻塞）。
4. **`tsconfig.json`** - 根，用 project references 指向 node/web 两个子配置。
5. **`tsconfig.node.json`** - main+preload（`@types/node`、CommonJS 友好、`outDir` 仅类型检查用）。
6. **`tsconfig.web.json`** - renderer（JSX、`@types/react`、DOM lib、路径别名 `@/*`->`src/*`）。
   > 说明：技术栈 §7 只列了单个 `tsconfig.json`，此处采用 electron-vite 官方三文件方案以保证 main(node) 与 renderer(dom) 类型环境分离、可正常通过 `tsc`。属对文档结构的工程化细化。
7. **`tailwind.config.ts`** - content 扫描 `./src/**/*` 与 `./src/index.html`；`darkMode: 'class'`；extend theme 映射 shadcn CSS 变量（border/input/ring/background/foreground/primary 等）。锁定 tailwind v3（shadcn + postcss 工作流稳定，不用 v4）。
8. **`postcss.config.js`** - `tailwindcss` + `autoprefixer`。
9. **`components.json`** - shadcn 配置：style=default、baseColor=slate、cssVariables=true、别名 components=`@/components`、ui=`@/components/ui`、lib=`@/lib`、utils=`@/lib/utils`。使 M6 `shadcn add` 即开即用。
10. **`.gitignore`** - node_modules、dist、out、release、.vite、*.log、.DS_Store。
11. **`.npmrc`** - 设 `ELECTRON_MIRROR` / `ELECTRON_BUILDER_BINARIES_MIRROR` 指向 npmmirror（国内下载加速，可删）。
12. **`README.md`** - 简短：项目名、技术栈、`npm install` / `npm run dev` / `npm run build` 说明。

### 主进程 + preload（入口）
13. **`electron/main/index.ts`** - `app.whenReady()` 创建 `BrowserWindow`，标题 `HiKey`；webPreferences 强制 `contextIsolation:true` / `nodeIntegration:false` / `sandbox:true`、`preload` 指向 `out/preload/index.js`；dev 载 `process.env.ELECTRON_RENDERER_URL`、prod 载 `out/renderer/index.html`；`window-all-closed` 退出（无托盘，对齐非目标）。
14. **`electron/preload/index.ts`** - `contextBridge.exposeInMainWorld('hikey', { ping: () => 'hikey-m1' })`，仅作桥接冒烟测试；真实 IPC API 留 M5。

### 渲染进程（入口 + shadcn 基建）
15. **`src/index.html`** - root `#root`、标题 `HiKey`、CSP meta（`default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src 'self'`，禁止外部导航与远程内容，`unsafe-inline` 仅为 Tailwind 运行时注入样式）。
16. **`src/main.tsx`** - React 18 `createRoot` 渲染 `<App/>`，引入 `./styles/globals.css`。
17. **`src/App.tsx`** - 极简占位页：Tailwind 样式标题 `HiKey - M1 脚手架` + 调用 `window.hikey.ping()` 显示结果（验证主↔渲染桥 + Tailwind 编译）。
18. **`src/styles/globals.css`** - Tailwind 三指令 + shadcn 主题 CSS 变量（`:root` 与 `.dark` 的 `--background/--foreground/--primary/--border/--ring` 等，slate 配色）。
19. **`src/lib/utils.ts`** - `cn()` = `twMerge(clsx(inputs))`。
20. **`src/env.d.ts`** - `/// <reference types="vite/client" />` + 声明 `interface Window { hikey: { ping: () => string } }`。
21. **`src/components/ui/.gitkeep`** - 空目录占位，M6 shadcn 组件落点。
22. **`resources/.gitkeep`** - 构建资源目录占位，M6 放图标。

## 依赖与版本策略
- **dependencies**：`electron`、`react`、`react-dom`。
- **devDependencies**：`electron-vite`、`vite`、`@vitejs/plugin-react`、`electron-builder`、`typescript`、`@types/node`、`@types/react`、`@types/react-dom`、`tailwindcss`(v3)、`postcss`、`autoprefixer`、`class-variance-authority`、`clsx`、`tailwind-merge`。
- **版本**：`electron` 按"固定主版本、锁定具体版本号"要求做精确 pin（不带 `^`），安装前 `npm view electron version` 取当前稳定版写入；其余用 caret。tailwind 锁定 v3 主版本。
- 包管理器用 npm（无额外工具链）。

## 安全基线（技术栈 §4.2，M1 即落地）
- `contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`。
- `index.html` CSP meta 启用，禁止远程内容与外部导航。
- 渲染进程不直接接触文件系统/Node（仅经 `window.hikey` 桥）。

## M1 完成验证标准
1. `npm install` 成功（零 native 依赖，无 electron-rebuild 报错）。
2. `npm run dev` 打开标题为 `HiKey` 的窗口，占位页以 Tailwind 样式正常渲染，`window.hikey.ping()` 返回 `hikey-m1`（证明 preload 桥 + Tailwind + React 全链路通）。
3. `npm run typecheck`（node + web 两套）零错误。
4. `npm run build` 产出 `out/main`、`out/preload`、`out/renderer` 无报错。
5. 安全检查：webPreferences 三项值正确、CSP meta 存在、无远程资源加载。
6. NSIS 安装包打包为 M6 验证项，M1 仅保证 builder 配置就位、`electron-vite build` 通过。

## 不在 M1 范围（明确排除）
lowdb 封装与 DB 文件（M2）、safeStorage（M2）、健康检测/providers（M3）、导入解析（M4）、IPC handler 注册与完整 contextBridge API（M5）、UI 组件与 shadcn 组件、NSIS 实际打包（M6）。
